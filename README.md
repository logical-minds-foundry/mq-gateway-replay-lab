# mq-gateway-replay-lab

Lab demo of resilient, replayable MQ message-gateway patterns: an MQ-native archive (two-put-under-syncpoint + mirrored inbound copy) with browse-based reconciliation and observability, proving "replay the unconfirmed" against a live HA/DR queue manager.
